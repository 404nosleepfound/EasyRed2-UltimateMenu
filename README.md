# Easy Red 2 - Ultimate Menu (Open Source)

This is the full source code for the **Ultimate Menu** mod for Easy Red 2.
Originally hosted on [Nexus Mods](https://www.nexusmods.com/easyred2/mods/31).

### Status: Discontinued / Looking for Maintainer
I no longer have the time to update or maintain this mod for newer versions of Easy Red 2. 
Anyone is welcome to fork this repository, fix bugs, update game hooks/offsets, and publish updated builds for the community.

### Built with:
- BepInEx 6 (IL2CPP)
- HarmonyX
- Unity IMGUI
